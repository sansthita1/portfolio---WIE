# Sansthita Awasthi | Personal Portfolio

**Live website:** https://sansthita1.github.io/portfolio---WIE/
**Repository:** https://github.com/sansthita1/portfolio---WIE

## Project Overview

A responsive personal portfolio website built for the IEEE WIE Mission 2 task.
It presents my background in Computer Science and Data Science at VIT Vellore,
along with my projects and skills.

**Purpose:** To showcase my work and make it easy for recruiters to see
what I have built and get in touch.

**Target audience:** Recruiters, internship coordinators, and fellow
students looking for a quick overview of my skills and projects.

## Features

- Hero section with a dynamic typing effect
- About section with a short introduction
- Featured projects with interactive filtering (All / Web / Data Science)
- Skills and tech stack grid
- Contact form with client-side JavaScript validation
- Smooth-scrolling navigation bar
- Fully responsive layout for desktop and mobile

## Technology Stack

- HTML5
- CSS3 (Flexbox, Grid, CSS variables, media queries, animations)
- JavaScript (vanilla)
- Deployed with GitHub Pages

## Setup Instructions

1. Clone the repository:
   `git clone https://github.com/sansthita1/portfolio---WIE.git`
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

No installation or build step is needed.
